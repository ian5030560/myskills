# 模型比較評分表（evaluate-paper × 3D-Mem）

用同一篇論文（`test-papers/cs.pdf`）與同一個研究問題，比較 opus、sonnet、haiku 的判讀。`test-papers/output/compare/ref/appraisal.md` 是我自己（本對話）做的參考報告，只作為對照，不是標準答案。

每項只記 ✔／✘／部分，不加總成分數。重點是看每個模型在哪些地方不一樣。

## A. 機械檢查（`check.ps1` 自動）
規則 1、4、5、8、9、12、14、16 的字串層檢查。

## B. 事實是否正確（對照論文）
| # | 項目 | 正確答案 |
|:---|:---|:---|
| B1 | DOI 與版本 | 10.1109/CVPR52734.2025.01612；所讀是 IEEE 會議論文集版，不是預印本 |
| B2 | 題名查詢的處理 | 候選只有一筆相符，沒有版本衝突；說明怎麼選 |
| B3 | 檢查表 | 沒有適用的標準檢查表，且不當成論文缺點（方法加基準測試）；沒有亂套 CASP 或 MMAT |
| B4 | 指標來源 | OpenAlex 與 Crossref 被引次數並列、不合併、有查詢日期；數字與各自的 `metrics.json` 一致（每日會變，不與 ref 比） |
| B5 | 撤稿 | 查無撤稿紀錄（不是「未被撤稿」） |
| B6 | 表 1 與表 2 的比較基礎 | 指出基準來自不同模型（GPT-4 與 GPT-4o）與不同題目範圍（557 題 vs 184 題子集） |
| B7 | GOAT-Bench | 指出只評估十分之一子集，且 Explore-EQA 有額外的成功標準 |
| B8 | 資源消耗 | 指出論文只給快照數量，沒有運算時間、詞元或記憶體 |
| B9 | 附錄 | 指出 PDF 沒有附錄，列在「仍需確認」，沒有假裝讀過 |
| B10 | 研究問題適用範圍 | 指出論文只限機器人 3D 室內場景，不能直接推到其他記憶系統 |

## C. 判斷品質
| # | 項目 | 看什麼 |
|:---|:---|:---|
| C1 | 用途標記合理 | 標記與理由一致；若標「主報告」，是否說明為何能承擔「影像在記憶系統怎麼處理」的一般論點 |
| C2 | 每個判斷都有位置 | 內容判斷每項有章節或表格位置 |
| C3 | 結果與詮釋分開 | 是否把作者的說法當成結果 |
| C4 | 不編造 | 有沒有寫出論文沒有的數字、章節或結果（逐一對照原文） |
| C5 | 未讀範圍誠實 | 「未讀」是否列出且與實際相符 |

## D. 成本（`check.ps1` 輸出）
成本（USD）、回合數、耗時。

## 結論怎麼寫
不給總分。寫成「哪個模型在哪幾項有差異」的清單，並標出：
- 哪些模型違反了寫在 SKILL.md／report-format.md 的硬性規則（A 與 B3、B5）；
- 哪些模型有編造（C4），這項最嚴重；
- 差異是出在規則寫得不夠清楚，還是模型能力，若是前者就是要改進 skill 的地方。
