# 03: 裁切腳本（剝邊規則）

**What to build:** AI 指定一張頁面圖和一個寬鬆的比例範圍，腳本從範圍邊緣往內剝除圖說、內文、章節標題、頁首頁尾、隔壁圖的細條與白邊，從 PDF 以 200 dpi、不含格線重新渲染出**裁切圖**，並印出實際使用的範圍。規格與各條門檻見 spec 的「Crop script」與「Crop trimming rules」（來自原型）。

**Blocked by:** 02（需要頁面圖的檔名規則與 manifest）

**Status:** ready-for-agent

- [ ] 輸入：頁面圖路徑、`x0,y0,x1,y1`（0–1 頁面比例）、名稱；頁碼取自檔名，PDF 取自 manifest
- [ ] 輸出 `images/<name>.png`，200 dpi、無格線
- [ ] stdout 印出最終範圍（頁面比例）
- [ ] 只往內收、不切進非下列類型的內容：圖說（`Figure N`/`Fig. N`/`Table N` 開頭）、章節標題、內文段落、頁首頁尾
- [ ] 內文段落判定：主要字級與全文最常見字級差 ≤0.6pt、至少一行 ≥60 字、寬度 ≥35% 頁寬（純文字條列組成的圖、字較小的表格不被剝）
- [ ] 左右邊緣：跨邊且在範圍內不到一半寬度的內文段落，把該側收到段落外
- [ ] 上下邊緣反覆剝除最外側的上述文字區塊；只計入與範圍垂直重疊 ≥4pt 的圖形
- [ ] 去白邊時，丟掉上下邊緣與主體間隔 ≥6pt、高度 <5pt 的細條；保留 2pt 邊距
- [ ] 剝到空或幾乎空時以非零狀態結束並說明需要重框
- [ ] 命令列測試（以印出的最終範圍驗證，不做影像分析）：圖形＋下方圖說＋內文＋頁首、寬鬆範圍 → 範圍排除圖說／內文／頁首且完整包住圖形；同頁上下兩張圖；純文字條列圖不被剝；跨側邊內文被切；剝到空回傳錯誤；輸出圖尺寸符合 200 dpi
- [ ] pylint 通過
